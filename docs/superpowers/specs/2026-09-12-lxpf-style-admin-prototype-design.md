# LXPF 风格企业级后台管理系统原型设计

**日期**：2026-09-12
**作者**：设计协作产出（brainstorming）
**状态**：设计已确认，待落地

---

## 1. 背景与目标

测试环境 `http://36.135.91.165:38583` 跑的是「LXPF 快速开发平台 v6.0.0」（青岛联信网络技术服务有限公司），与本地 `qa-system`（NL2SQL 智能问答系统）是两个不同的产品。本仓库以 LXPF 平台为**视觉/交互风格参考**，产出一套**企业级后台管理系统的静态原型设计文件**，作为设计资产沉淀与未来项目起步模板。

**目标**
- 沉淀 LXPF 风格的视觉与交互语言（设计 token、组件、布局）
- 提供 13 个可直接预览的高保真 HTML mockup（8 PC + 5 H5）
- 不绑定具体业务、零依赖、零构建、可双击即开
- 作为后续真实项目的设计起步模板

**非目标**
- 不实现真实业务逻辑
- 不引入 npm / 构建工具 / 外部 CDN
- 不画真实图表（dashboard 图表用占位 SVG 框）

## 2. 项目结构与目录

```
lxpf-style-admin-prototype/
├── README.md                    # 项目说明、预览方式、扩展指南
├── index.html                   # 总览页（卡片导航到所有 mockup）
├── design-system.html           # 设计系统总览（token + 组件 showcase）

├── assets/
│   ├── tokens.css               # 颜色 / 字号 / 间距 / 圆角 / 阴影 / 断点
│   ├── base.css                 # reset + 全局样式 + 字体
│   ├── components.css           # 按钮 / 输入 / 选择 / 表格 / 卡片 / Tag / 分页 / 抽屉 / 对话框
│   ├── layout-pc.css            # PC 框架：顶栏 + 侧边栏 + 面包屑 + 内容区
│   ├── layout-h5.css            # H5 框架：底部 Tabbar + 顶部 Navbar
│   └── icons.svg                # 内联 SVG 雪碧图（统一图标）
│
├── pc/                          # PC 端 8 个页面
│   ├── login.html               # 登录（含二维码、第三方登录、协议）
│   ├── workbench.html           # 工作台（待办 + 快捷入口 + 数据概览）
│   ├── list.html                # 列表页（搜索/筛选/批量操作/分页）
│   ├── form-edit.html           # 表单编辑（基础/分组/校验/上传）
│   ├── dashboard.html           # 数据看板（KPI + 折线/柱/饼 + 钻取）
│   ├── permission.html          # 权限管理（角色树 + 资源树 + 矩阵）
│   ├── settings.html            # 设置中心（Tab + 表单）
│   └── 404.html                 # 空/错误页
│
└── h5/                          # H5 端 5 个页面
    ├── login.html               # 登录（手机号/验证码/密码）
    ├── home.html                # 首页（卡片 + 数字 + 列表）
    ├── list.html                # 列表（搜索 + 卡片 + 下拉刷新）
    ├── detail.html              # 详情（头图 + 信息 + 操作）
    └── profile.html             # 我的（头像 + 菜单 + 退出）
```

**约束**
- 每个页面 `<head>` 引用 4 个 CSS：`base → tokens → components → layout-*`
- 不引 JS 框架；仅极少量原生 JS（分页交互、抽屉开关）
- 所有 mockup 内容用真实中文示例数据（不写 lorem ipsum）

## 3. 视觉系统（Design Token）

### 3.1 色板（深青 + 中性灰，贴近 LXPF v6 风格）

| 角色 | Token | 值 | 用途 |
|---|---|---|---|
| 主色 | `--color-primary` | `#0958d9` | 主按钮、链接、激活态 |
| 主色-浅 | `--color-primary-50` | `#e6f4ff` | 选中背景、Tag 背景 |
| 主色-深 | `--color-primary-700` | `#003eb3` | hover / pressed |
| 辅助青 | `--color-accent` | `#13c2c2` | 图表、强调 |
| 成功 | `--color-success` | `#52c41a` | 成功态、通过 |
| 警告 | `--color-warning` | `#faad14` | 提示、待处理 |
| 错误 | `--color-danger` | `#ff4d4f` | 删除、错误 |
| 信息 | `--color-info` | `#1677ff` | 次级提示 |
| 中性-文字主 | `--text-primary` | `rgba(0,0,0,0.88)` | 标题、正文 |
| 中性-文字次 | `--text-secondary` | `rgba(0,0,0,0.65)` | 副标题、说明 |
| 中性-文字辅 | `--text-tertiary` | `rgba(0,0,0,0.45)` | 占位、禁用 |
| 中性-边框 | `--border-color` | `#d9d9d9` | 默认边框 |
| 中性-分割线 | `--divider-color` | `#f0f0f0` | 单元格分隔 |
| 中性-背景 | `--bg-base` | `#f5f7fa` | 页面底色 |
| 中性-容器 | `--bg-container` | `#ffffff` | 卡片/弹层 |
| 中性-悬浮 | `--bg-hover` | `#fafafa` | 行 hover |

### 3.2 字号

| Token | 值 | 用途 |
|---|---|---|
| `--font-size-xs` | 12px | 辅助、Tag |
| `--font-size-sm` | 13px | 表头、按钮 |
| `--font-size-base` | 14px | 正文、输入 |
| `--font-size-md` | 16px | 标题 h4 |
| `--font-size-lg` | 18px | 弹层标题 |
| `--font-size-xl` | 20px | 页内标题 |
| `--font-size-2xl` | 24px | 大数字、欢迎语 |
| `--font-size-3xl` | 30px | KPI 数值 |

### 3.3 字重

- `--font-weight-regular: 400`
- `--font-weight-medium: 500`（导航、按钮、表格头）
- `--font-weight-semibold: 600`（标题、KPI）

### 3.4 间距（4 倍数）

`--space-1: 4px` · `--space-2: 8px` · `--space-3: 12px` · `--space-4: 16px` · `--space-5: 20px` · `--space-6: 24px` · `--space-8: 32px` · `--space-10: 40px`

### 3.5 圆角

`--radius-sm: 2px` · `--radius-base: 4px` · `--radius-md: 6px` · `--radius-lg: 8px` · `--radius-pill: 999px`

### 3.6 阴影

- `--shadow-sm: 0 1px 2px rgba(0,0,0,0.04)`
- `--shadow-base: 0 2px 8px rgba(0,0,0,0.08)`（卡片、抽屉）
- `--shadow-lg: 0 6px 16px rgba(0,0,0,0.12)`（弹层）

### 3.7 断点

`--bp-mobile: 480px` · `--bp-tablet: 768px` · `--bp-desktop: 1024px` · `--bp-wide: 1280px`

### 3.8 字体栈

- 中文：`"PingFang SC", "Microsoft YaHei", system-ui`
- 西文：`"Inter", -apple-system, "Helvetica Neue", Arial`
- 数字：`"Roboto Mono", ui-monospace`（KPI 用）

### 3.9 暗色模式

- 所有 token 走 CSS 变量，支持 `@media (prefers-color-scheme: dark)` 与 `[data-theme="dark"]` 双触发
- 暗色背景 `#0d0d10`、容器 `#17171a`、文字 `rgba(255,255,255,0.85)`（与 LXPF loading 主题对齐）

## 4. 组件库

| # | 组件 | 关键变体 |
|---|---|---|
| 1 | **按钮 Button** | 类型：primary / default / dashed / text / danger / link；尺寸 large(32) / default(28) / small(24)；状态 default / hover / active / disabled / loading（loading 用 `::after` 旋转圆） |
| 2 | **图标 Icon** | 24px 线性图标集 30+：home、user、setting、bell、search、filter、plus、edit、delete、eye、download、upload、check、close、menu、logout、chart、team、file、tag、calendar、location、message、star、lock、arrow-* |
| 3 | **输入 Input** | text / password / number / textarea / search；尺寸 large / default / small；状态 default / focus / error / disabled / with-prefix / with-suffix / allowClear |
| 4 | **选择 Select** | 用 `<details>` + CSS 实现下拉展开；单选、多选、搜索、可清空、含 Tag |
| 5 | **日期选择 DatePicker** | 输入框 + 日历浮层（输入框显示日期，浮层静态展示本月日历） |
| 6 | **表格 Table** | 列：复选框 / 序号 / 主字段 / 状态 Tag / 操作；斑马纹、排序箭头、表头固定、行 hover、批量操作工具栏、分页器、内嵌展开行（仅 PC） |
| 7 | **卡片 Card** | 标题 + 右上角操作 + 内容；变体：默认、有底色（dashboard）、可点击（hover 上抬） |
| 8 | **Tag 标签** | 颜色 default / primary / success / warning / danger / processing（loading 动画）；形态：可关闭 / 不可关闭 |
| 9 | **徽标 Badge** | 数字徽标 / 状态点 |
| 10 | **提示 Tooltip / Popover** | 用 `<details>` 模拟下拉浮层；4 个方位 |
| 11 | **抽屉 Drawer** | 右侧抽屉（width 480），含遮罩 + 关闭按钮；用于详情 / 编辑 |
| 12 | **对话框 Modal** | 居中弹层，含标题 / 正文 / 确认取消按钮组；尺寸 small / default / large |
| 13 | **消息提示** | 顶部居中悬浮条 success/info/warning/error 四态；3 秒后渐隐（CSS 动画） |
| 14 | **分页 Pagination** | 总数 + 页码 + 每页条数 + 跳转；变体 default / simple / mini（H5 用 mini） |
| 15 | **面包屑 Breadcrumb** | 横向 `>` 分隔，当前页灰色不可点 |
| 16 | **页签 Tabs** | line / card 两种风格；含 badge 与禁用项 |
| 17 | **进度条 Progress** | 线形 + 圆环（dashboard 用）；颜色随进度 success/warning/danger |
| 18 | **头像 Avatar** | 圆形 + 文字 fallback；尺寸 24/32/40/64；状态点 dot |
| 19 | **空状态 Empty** | SVG 插画 + 主标题 + 副标题 + 主操作按钮 |
| 20 | **骨架屏 Skeleton** | 段落骨架 + 圆形骨架；表格骨架行；卡片骨架 |

### 4.1 PC 特有

- 顶栏 TopBar（高 56px）：Logo + 全局搜索 + 帮助 + 通知 Bell（带 Badge）+ 用户头像下拉
- 侧边栏 Sidebar（宽 220px / 折叠 64px）：两级菜单 + 当前高亮 + 图标 + 徽标
- 多页签 PageTabs（高 38px）：类似浏览器标签，可关闭、可拖拽排序（静态）

### 4.2 H5 特有

- 顶部 NavBar（高 44px）：返回 + 标题 + 右侧操作
- 底部 Tabbar（高 56px）：4 个图标 + 文案
- 下拉刷新区、加载更多
