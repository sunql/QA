三条硬规则（都有集成/单测钉住）：

1. **无源词条不挂类** —— 挂了类 = 告诉 LLM「去查这张表」⇒「0 行 = 真的是 0」假答案比查不到更坏。
2. **未确认口径如实标注** —— 问卷 A5.1「目前不定，后续通过系统配置」⇒ 只写源系统事实 + 显式「待业务确认」。
3. **到货 ≠ 收货** —— 指标口径一律以收货日期/数量为准（A1.2/A3.2 答复）。

## 3. 应用脚本语义

- **默认 dry-run**：只比对不写库；`--apply` 才落库。
- **幂等**：不存在 → 创建（`created_by = ops-procurement-terms`）；字段完全一致 → 跳过；不一致 → **报 `[DRIFT]` + exit 2**。
- **不静默覆盖**：term_dictionary 没有 update 端点；覆盖会丢掉人工改动 ⇒ 漂移必须人工裁决
  （先裁决是「有人在后台改了口径」还是「目录改了没落库」，再同步一侧）。
- 目录的 `evidence` 字段不落库，用于漂移时的裁决上下文与本文档表格。
