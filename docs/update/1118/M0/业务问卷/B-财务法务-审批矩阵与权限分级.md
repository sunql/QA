# 业务问卷 B · 财务 + 法务：审批矩阵与权限分级

**收件人**：财务（资金/付款）+ 法务（合同/合规）
**预计耗时**：45–60 分钟
**为什么问你们**：系统要落地"询价 → 比价 → 定标 → 审批 → 订单"这条链，就必须知道**谁能批、批到哪一层、哪些动作系统永远不许自己做**。这三件事法律上出不了第二份，代码里也写不出来。

> **工程侧现状（供对照）**：工作流框架已建成（定义 / 实例 / 步骤 / 命令 / 审批任务 / outbox 六张表），审批矩阵目前是**纯数据**——放在 `workflow_definition.definition_json` 的 `approvalMatrix` 里，每条矩阵项有一个 `matrix_code`（条目 key）和期望审批角色 `approver_role`。**系统目前没有任何真实业务矩阵数据**，全靠你们给。
