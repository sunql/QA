- **环境**：commit `e09f58ce`（M5 全链 + M6-1 端口）/ 6 开关全开 / 真实 HTTP + 真实登录 / dev 栈
- **期望答案**：见附录 B ——「Copilot + Command Draft：**只生成草稿、不触发发送**」
- **实际答案**（全部经真实 HTTP，用户 admin）：
  1. `POST /procurement/rfqs/drafts`（`Idempotency-Key: q06-h-2`，真实供应商 81324035971）
     ⇒ **201，status=DRAFT**
  2. 幂等重放（同 key 同 payload）⇒ **200，同 rfqDraftId**
  3. 同 key **异** payload ⇒ **409**
  4. `POST .../validate` ⇒ VALIDATING；`POST .../submit-approval` ⇒ PENDING_APPROVAL
  5. 审批前 `POST .../approve` ⇒ **409**「不在审批中」；**`/send` 端点当时 404（D-4：M5 阶段无发送）**
  6. 他人审批（sunql）⇒ READY_TO_SEND；决策链 `[(SUBMIT,admin),(APPROVE,sunql,'Q06 审批通过')]`
  7. 终态再决策 ⇒ **409**；自批（admin 提交 + admin 审批）⇒ **409**
- **数值来源**：上述响应原文（草稿 id / 版本号 / 决策链均由 DB 直出）
- **判定**：✅ **一致**（草稿生成、**不触发发送**、幂等、审计、自批禁止全部满足）
