## 三、验收矩阵（三轴）

### 轴 1：身份（域可见性）

| 场景 | 期望 | 覆盖 |
|---|---|---|
| 域主组织的成员 | 查得到（四路按权限返回证据） | 集成 `test_org_member_of_primary_org_can_query_the_domain`；单测 `test_realRoutesStampReleaseVersionOnEveryEvidence` |
| 域主组织的**非**成员 | **查不到**：200 + 空结果 + 警告 + 四路 `DENIED` | 集成 `test_invisible_domain_returns_empty_with_warning`；单测 `test_invisibleDomainDeniesEveryRoute` |
| 域**无主组织**（`primary_org_id IS NULL`） | 非 admin **查不到**（fail-closed，L-P4-1） | 集成 `test_domain_without_primary_org_is_invisible_to_non_admin` |
| 域不可见时**一路都不许跑** | 记录型假路由收到的 `RouteInput` 为**空**（不许「先查了再判断能不能给」） | 单测 `test_invisibleDomainDeniesEveryRoute`（断言 `inputs == []`） |
| 域不可见时**连发布面都不解** | 发布解析器**零调用**；响应里 `release.degraded=True` 且 `id/version=None` | 单测 `test_invisibleDomainNeverTouchesTheReleaseResolver` |

### 轴 2：请求侧收窄（只能收窄，不能放宽）

| 场景 | 期望 | 覆盖 |
|---|---|---|
| 收窄**只发生在权限源一处** | 权限源被调用**恰好一次**，且拿到的是 `request.scope` **同一个对象** | 单测 `test_requestScopeIsHandedToThePermissionSourceOnly` |
| 请求指定**无权组织** | 域 ∩ 请求 ⇒ 该域**查不到**（200 + 空 + 警告 + 四路 `DENIED`） | 集成 `test_request_scope_narrowing_can_hide_the_domain` |
| `entityHints` | **不放宽**可见性（带 hints 的响应证据与不带 hints 的**完全一致**） | 集成 `test_entity_hints_do_not_widen_access` |
| 请求侧 `maxSecurityLevel` | 只能往下收窄（`min`） | 单测 `permission` 模块（`narrowSecurityLevel`） |

### 轴 3：引用可回溯

| 场景 | 期望 | 覆盖 |
|---|---|---|
| **真路由**跑一遍 | 每条证据都带 `releaseId=7` / `releaseVersion="2026.11.16-1"` / `source=RELEASE` | 单测 `test_realRoutesStampReleaseVersionOnEveryEvidence` |
| 逐路断言（HTTP 层） | GRAPH / METRIC / SQL 三路**逐条**证据都带版本与 `source=RELEASE` | 集成 `test_every_route_evidence_is_traceable_to_release`（参数化三路） |
| 发布面不可用 | 四路一律 `DEGRADED` + 原因；`release.id/version` **皆为 None**；**无证据** | 单测 `test_degradedReleaseMakesEveryRouteDegradedAndStripsVersions`；集成 `test_knowledge_query_reports_degraded_release_without_version` |
| RAG 路收窄 | 过滤器四维 = 同一份发布面 + 权限口径（`releaseId` / `domainCodes` / `orgCodes` / `entityTypes`） | 单测 `test_ragRouteFiltersByReleaseAndScope`（D34） |

### 错误处理（沿用 D34 的编排层兜底）

| 场景 | 期望 | 覆盖 |
|---|---|---|
| 单路抛未预期异常 | 该路 `DEGRADED` + 原因，**其余三路照常返回** | 单测 `test_oneFailingRouteDoesNotBreakWholeQuery`（D34） |
| 能力未启用（RAG 开关关） | `DEGRADED` + 原因，**零外部调用**（不发起 embedding、不查 Milvus） | 单测 `test_ragRouteDegradesWhenSwitchIsOff`（D34） |

## 六、开发过程中真实踩到并修掉的坑

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | `test_invisibleDomainNeverTouchesTheReleaseResolver` 红：`assert ['PROCUREMENT'] == []` | 测试自己给的 scope 里**域是可见的**（`_scope()` 默认 `PROCUREMENT`）⇒ 本来就会解发布面 | **改测试**：换成隐藏域的 scope 解析器（`_scope(domainCodes=("QUALITY",))`）⇒ 断言成立 |
| 2 | 差点把「域不可见」写成「发布面不可用」的同一件事 | 两条轴：可见性在**发布面之前**判（C-1），发布面不可用是**可见域里的降级** | 矩阵拆成两行分别钉住（`inputs == []` / 四路 DEGRADED） |

---

## 七、约定沉淀（避免下一批再踩）

1. **同源要断言身份，不只断言相等**：`inp.scope is scope` 才是「同一个对象」的硬证据。
2. **矩阵要覆盖负向格**：「无主组织」「请求指定无权组织」「实体提示」三条负向格最容易漏。
3. **越权侧漏也算越权**：域不可见时**连发布面都不许解**（版本号在不在 = 域存不存在的探针）。
4. **降级必须剥版本号**：`release.id/version` 为 None + 降级原因 ⇒ 不许挂旧版本充数。
5. **收窄只留一处**：权限源之外不许再收窄；各路只**消费**口径。
6. **RAG 正向格只能靠单测**：集成环境无 P3a 开关 / 无 Milvus v2 数据 ⇒ RAG 的 `OK` 态用**注入闸门替身**的单测覆盖，并在矩阵里注明（见 §八）。
