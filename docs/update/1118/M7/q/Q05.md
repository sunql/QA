# Q05 对比三家供应商历史采购价格和交期。

- **问题原文**：对比三家供应商历史采购价格和交期。
- **环境**：commit `e09f58ce` / 业务库 = ds1 THBI Oracle
- **实际答案**：**未执行**——能力已具备但缺执行窗口：
  - `purchase_history_query` 工具（M3-2）：两段确定性 SQL（汇总价格区间 + 明细）经 SQL Guard + adapter 只读；
  - `quotation_query` 工具（M3-4）：落 `DWD_PURCHASE_QUOTATION_YEARLY_DTL`（源侧实测 167,909 行，
    ITEM_CODE/SUPPLIER_CODE/SEG_YEAR/UNIT_PRICE_EX_TAX 100% 填充）。
- **阻塞**：两项工具均需 **Agent 运行链路**（`POST /api/v1/agent-runs`，需 registry warmUp + 工具绑定），
  且真实查询要连 THBI Oracle（dev 栈到 Oracle 的网络未验证）。
- **判定**：⚠️ **能力就绪 / 证据未取**——建议在 M7 验收窗口用真实 Oracle 连接跑一次并归档
  （工具契约有测试覆盖，缺的是端到端数值证据）。
