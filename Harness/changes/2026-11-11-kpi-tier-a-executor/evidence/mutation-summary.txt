## 变异 4：Tier B 分支返回 `None`（落 L4）

- 文件：`backend/app/services/chat_stream_output.py:537-541`
- 改前：

```python
                if plan.tier == TIER_B:
                    # L4 不注入契约块：Tier B 必须交给主 NL2SQL 流水线。
                    return self._tierBPreamble(
                        match, kpi, plan.reason, dto.datasourceId
                    )
```

- 改后：

```python
                if plan.tier == TIER_B:
                    # MUTATION 4: return None instead of Tier B sentinel
                    return None
```

- 命令：

```bash
python -m pytest app/tests/unit/test_chat_tier_a_preamble.py::test_tier_b_returns_sentinel_and_skips_l4 -q
```

- RED（符合预期）：

```text
FAILED app/tests/unit/test_chat_tier_a_preamble.py::test_tier_b_returns_sentinel_and_skips_l4
E       assert None is not None
app/tests/unit/test_chat_tier_a_preamble.py:112: AssertionError
1 failed in 1.12s
```

- 与计划表的差异（如实记录）：
  1. brief 括号里写「落 L4」。当前代码把 Tier B 哨兵放在 `if plan.tier == TIER_A /
     elif TIER_C / else(LEGACY)` **之前**；把该 `return` 删空（`pass`）会让 Tier B
     落进 `else`（LEGACY），实际红在 `assert preamble.routing_layer == "L1B"`，
     得到 `'L1' == 'L1B'`。这不是「落 L4」。
  2. 因此按字面语义「Tier B 分支返回 `None`」取 `return None`：函数提前结束，
     调用方拿不到哨兵、继续主 NL2SQL 路径，用例红在 `assert preamble is not None`。
     两种写法都把 Tier B 哨兵打掉，本记录采用与变异描述一致的后一种。
- 还原后：`1 passed in 1.10s`。
