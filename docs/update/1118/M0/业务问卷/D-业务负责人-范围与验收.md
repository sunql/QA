# 业务问卷 D · 项目业务负责人：范围与验收

**收件人**：项目业务负责人（采购域业务 owner）
**预计耗时**：约 30 分钟
**为什么问你们**：前面三份问卷给的是**口径**，这份给的是**边界**——"这次到底做到什么算完"。没有这一份，验收时没有客观依据；有了这一份，我们才知道**不该做什么**，从而把 94–144 人日的范围压住。

| 问 | 回答 |
|---|---|
| D3.1 首期是否接受**"只生成草稿、由人工发送"**？ | ▸ |
| D3.2 若必须打通外发，需要哪几道前置（审批 / 二次确认 / 供应商白名单 / 金额上限）？请给出**必须有的那几道**。 | ▸ |

## 回填指引

- 第 2 部分的问题清单**越具体越好**——带上真实物料、真实供应商、真实时间段（例如"2026 年 Q3 华东工厂的铝合金法兰供应商"），抽象问题测不出真问题。
- 拿不准的写 `不确定`——**这是有效答案**，工程侧会据此降级，不会卡住。
- 优先级取舍请给**明确顺序**，不要给"都重要"。
