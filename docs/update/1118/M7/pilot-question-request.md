平台代码侧已就绪（M0–M6：知识检索 / KPI 直算 / 图谱 / 文档检索 / 询价草稿 / 审批 / 发送端口）。

⇒ 请提供你们**平时真的会问**的 20–30 个问题（不是考试题），我们逐条跑通并归档证据。

## 二、每条问题请这样填写（一次一条，可复制）

```
问题原文：            （用你们日常工作里的原话，不用改写成"系统友好"的问法）
期望答案：            （你们认为正确的答案是什么；数字请给出）
口径/时间范围：       （例如"2026 年 1–10 月"、"近 12 个月"、"全部在册供应商"）
涉及对象：            （供应商 / 物料 / 订单 / 收货 / 发票 / 付款 / 制度 / 合同）
优先级：              P0 必须过 / P1 应该过 / P2 可以晚
答案依据希望来自：    （ERP 表 / 数仓 / 制度文档 / 合同 / 人工经验）
```

## 三、建议的覆盖面（按平台已具备的能力，便于"问得出、答得上"）

| 类别 | 建议条数 | 已具备能力（可以这样问） |
|---|---|---|
| 实体 + 供应关系 | 4–6 | 「哪些供应商能供 X 物料」「某供应商供哪些物料」 —— 图查询实测：Supplier 638 家、供应边 11 万+（例：D135 供应商可供应 22,797 个物料） |

| 风险与合规 | 3–4 | 「某供应商有没有质量/合规风险」 —— 风险服务逐项给出特征、阈值、是否达标 |
| 制度/合同条款 | 4–6 | 「询价必须邀请几家」「某品类的准入要求」 —— **需先提供可导入的制度/合同文档**（当前文档目录 0 份） |
