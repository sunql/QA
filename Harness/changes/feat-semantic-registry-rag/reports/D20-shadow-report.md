## 3. 硬断言

- 过滤正确（v2 == 精确真值）：✅ 通过（少召回 = 该召回没召回；多召回 = 不该召回却召回了）
- 无未授权泄漏：✅ 通过（带范围过滤的召回里没有范围外的行，也没有未归域的行）
- 向量未漂移：✅ 通过（v2 向量与 v1 逐字节相同 ⇒ 回填没有重算向量）
