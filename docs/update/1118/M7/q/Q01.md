# Q01 哪些供应商可以供应指定物料？

- **问题原文**：哪些供应商可以供应指定物料？
- **环境**：commit `e09f58ce` / 6 开关全开 / 数据源 = ds1 THBI Oracle / 本地 dev 栈
- **期望答案**：见问卷 D D2.2 —— ⚠️ **D2.2 为空白（G-05/R-04）**，本问按设计稿附录 B 的验收关注点执行
- **实际答案**：以真实供应商 `D135`（鼎冠模具配件（苏州）有限公司）为例，其可供应物料经
  `GET /api/v1/procurement/knowledge/graph/neighbors?entityType=Supplier&entityKey=D135&maxHops=1&relationTypes=SUPPLIES`
  返回 **200 条 SUPPLIES 边**（`truncated=true` —— 边数上限 200 自证），终点全部为 `ItemMaster`。
- **Evidence 列表**：
  - `channel=GRAPH, kind=?` —— 本条走**受控邻接端点**（M2-2b），不是 knowledge/query 的 Evidence DTO；
    原始响应即证据：`nodes=201, edges=200, truncated=true, effectiveRelationTypes=["SUPPLIES"]`，
    样例行 `Supplier D135 --SUPPLIES--> ItemMaster 54011031OP50801`
- **数值来源**：Neo4j 业务图实测 `MATCH (s:Supplier)-[r:SUPPLIES]->(m:ItemMaster)`：
  Supplier 638 个 / ItemMaster 100,743 / PurchaseOrder 86,919；边数最多的三家 D135=22,797 / Q241=11,835 / C167=9,583
- **判定**：✅ **结构可用**（关系白名单 + truncated 自证 + 真实图数据）；
  ⚠️ 未与业务期望比对（D2.2 空白）
- **修正记录**：本问首次探测暴露 M2-2b 端点缺陷——非法 `entityType`（如 `Material`）抛
  `ValueError` 直穿 **500**；已修为 422（与 `/graph/traverse` 同口径），并加守卫用例。
