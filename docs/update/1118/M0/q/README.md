## 三个必须双向断言的点

1. 正确的问题 ⇒ 答案**对**；
2. 越界的问题（未接入数据域）⇒ 系统**明确说"未接入"**，不是编一个数；
3. 权限外的问题 ⇒ **被过滤**（不是拒答、也不是照答）。

> 第一题的模板可从本文件复制；**判定必须是二值**，不接受"基本一致"。
