## PR #115 CI 首轮（`795ff8d9`，run `42716364389`）

- 闸门自己的 check（`merge-gate / failure-set-diff`，id `129522856533`）判
  **退出码 1 / NEW_FAILURES**，净新增 2 条：`test_every_route_declares_the_admin_guard[requireAdmin]`
  与 `[getCurrentUser]`（7 条路由全判「无门禁」）。
- 根因：`uv.lock` 锁 **fastapi 0.141.1**，≥0.141 把 `include_router(dependencies=[...])`
  放进 `_IncludedRouter.include_context`，**不并入** `route.dependant`；本地 venv 0.136.1 会并入。
  详见 `D10.md` 评审处置 #4 与流程教训。
- ⚠️ **本地重跑 `ci_failure_set` 对这一 run 会给出退出码 4 / COVERAGE_MISMATCH（伪）**：
  闸门用 `POST /check-runs` 创建的 check 会被归入该 run 的 jobs 列表，事后本地对差就多出一个
  「job」。闸门自己评估时该 check 尚不存在。⇒ **权威判据是 check-run 的 output.title/summary**，
  不是事后本地重跑；若要本地复算，应在新 sha 的 CI 刚跑完、gate 尚未落 check 的窗口内做。
