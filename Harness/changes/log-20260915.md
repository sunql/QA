## 三、关键设计决策

1. **scope 多选 AND 组合**：`datasource_id` 单选粒度足够，`target_tables` / `rule_types` 改 list 字段；空列表走 None 短路避免 SQL `IN ()` 语法错
2. **snapshot 异步化**：用 FastAPI `BackgroundTasks` + DB JSONB 进度 + 前端 1s 轮询三件套，避免引 Redis/Celery 重型依赖；catch-all 兜底写 FAILED + progress.message
3. **session 自管**：`runSnapshotJob` 用 `getSessionFactory()` 拿新 session，不复用请求 session（请求 session 会 close）
4. **路由注册顺序**：`/reports/{report_id}/progress` 必须注册在 `/reports/{report_id}` 之前，否则被路径参数匹配吞掉
5. **前端轮询清理**：useEffect 必须在 cleanup 里 clearInterval，避免组件卸载后继续跑
