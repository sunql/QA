# 多工厂 PBOM 建模指南

一句话：在单一 PBOM 中管理"工序归属不同工厂 / 部分工序外协 / 跨厂装配 / 直发客户"四类场景的可计算数据模型。

## 详细说明

### 四类跨厂场景

| # | 模式 | 物料流 | 谁收最后成品 | 谁发客户 |
|---|---|---|---|---|
| A | 工序外协（委外加工） | 主厂供毛坯 → 外协厂精加工 → **返回主厂** | 主厂 | 主厂 |
| B | 跨厂装配（集团内） | 主厂做半成品 → 协作厂总成 → **直发客户** | 协作厂 | 协作厂 |
| C | 包工包料外协 | 外协厂自购料 → 出成品 → 主厂或直发 | 看条款 | 看条款 |
| D | VMI / 供应商代发 | 主厂供料给外协厂 → 外协厂 **直送客户** | 客户 | 外协厂 |

### 数据模型（在 [[pBOM 重构方案]] 的 10 张 sheet 上扩展）

#### 字段补强

- **02_PBOM_NODE**：加 `生产工厂 / 工厂类型 / 可供应工厂 / 是否虚拟件`
- **03_PBOM_OPERATION**：加 `工厂 / 工厂类型 / 外协类型 / 是否跨厂边界`
- **04_OPERATION_MATERIAL / 05_RESOURCE / 06_CAPACITY / 07_MATERIAL_CONSUMPTION / 08_AUXILIARY_CONSUMPTION**：加 `工厂`
- **10_WIP_POLICY**：加 `工厂 / 跨厂运输天数 / 跨厂运输方式`
- **01_PBOM_HEADER**：加 `最终发运工厂 / 是否直发客户 / 集团内协作厂 / 外购供应商`

#### 三张新 sheet

- **00_PLANT_MASTER**：工厂主数据（工厂代码 / 名称 / 地址 / 币种 / 税号 / 集团内部 / 主工厂）
- **11_PBOM_PLANT_FLOW**：PBOM 工厂流转主线
  - 列：PBOM / Node ID / 物料编码 / 物料名称 / 工序ID / 工序名 / 工厂 / 工厂类型 / 外协类型 / 上游工序ID / 下游工序ID / 跨厂边界 / 是否最后总成 / 是否直发客户 / 在途天数 / 运输方式
  - **作用**：3-4 行就能讲清"主厂做哪几步、外协做哪几步、最后谁发给客户"
- **12_CROSS_PLANT_LOGISTICS**：跨厂物流细则
  - 列：PBOM / 物流ID / Node ID / 物料编码 / 物料名称 / 发货工厂 / 收货工厂 / 距离km / 在途天数 / 运输方式 / 运输费用/件 / 单托数量 / 托盘类型 / 收货方质检 / 退货条款
  - **作用**：把跨厂物流的可计算属性（成本/在途/质检/退货）落表，与工艺路线解耦

#### 虚拟跨厂工序（关键约定）

| 工序号 | 用途 |
|---|---|
| **OP990** | 跨厂物流（计入在途天数） |
| **OP991** | 收货质检（入库前） |
| **OP999** | 直发客户（成品段） |

让工序流连续不断——MRP 不会因为中间空档算错提前期。

### 工厂分配规则（混合策略）

| 工序 / 制造方式 | 工厂 | 工厂类型 |
|---|---|---|
| 注塑 | `PLANT-B` | 集团内协作厂 |
| 冲压 / 焊接 / 组装 | `PLANT-A` | 主厂 |
| 外购（make=外购） | `SUPPLIER-S1..S3` | 外购供应商（按物料号 hash 散布） |
| 外协（make=外协） | `SUPPLIER-OUTSIDE` | 委外供应商 |

> 落地时这层映射应该由"工厂分配策略表"驱动（如按工序类型、按物料编码前缀、按客户指派），不允许在数据生成处硬编码。

### 关键运营规则（必须落到数据上）

1. **跨厂在途 = 工序 OP990**。MRP 把跨厂物流当工序计算提前期，值取自 12_LOGISTICS。
2. **外协类型决定成本字段**：
   - 工序外协 → `加工费/件`（主厂自供料）
   - 包工包料 → `采购单价`（价税合一）
3. **质检节点**：外协交货由收货厂质检，逻辑上算 OP990 的子步，记入 11 备注或单独一列。
4. **工厂代码进主数据**：所有 sheet 引用工厂代码而非自由文本，避免 "PLANT-A / plantA / 苏州厂" 三个值指同一实体。
5. **直发客户要在 HEADER 层标注**：`01_PBOM_HEADER.是否直发客户` 整单 PBOM 级别生效。
6. **运费 / 在途按工厂对预设**：不要逐单算，12_LOGISTICS 用工厂对距离查表。

### 适用 PBOM 案例

`pBOM_multisite.xlsx`（基于制动踏板总成 7196B1000001 重构）：

- 主产品 N001 制动踏板总成 — 总成组装在 PLANT-A
- 3 个注塑件（N002 主支架 / N006 踏板罩 / N007 球窝支架）— 在 PLANT-B 加工后跨厂运回
- 8 个外购件（缓冲块 / 球窝总成 / 踏板垫 / 外轴 / 球窝垫片 / 润滑轴套 / 回转轴 / 防松挡卡）— SUPPLIER-S1/S2/S3 跨厂采购
- 1 个委外件（N008 踏板臂组件 电泳）— SUPPLIER-OUTSIDE
- N001-OP999 直发客户

12 条跨厂物流覆盖全部非主厂件。
