# 业务问卷 C · ERP / SRM 系统管理员：源系统接口与映射

**收件人**：ERP 管理员、SRM 管理员、供应链数仓（DBA）负责人
**预计耗时**：约 60 分钟
**为什么问你们**：系统现在能"理解"采购业务，但**还不知道数据从哪个源系统的哪张表来**。当前库里 99 个本体类里 34 个是采购相关的 DWD/DIM 类，每个类只有 `source_table`（表名），**没有任何字段把它连到"哪个源系统"**——本体类层、本体指标层**都没有源绑定机制**（只有 `kpi_catalog` 和 `feature` 两张表带 `datasource_id`）。这是 M1「采购语义可发布」要新建的第一张绑定表。填错=后面全部查错表。

> ⚠️ **账号密码不要写在本文档里。** 账号请走内部渠道单独给（见 README §5）。
