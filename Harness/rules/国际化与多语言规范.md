# 国际化与多语言规范

## 目标

在不破坏现有功能的前提下，支持中文（zh-CN）向其他语言扩展。

## 现状

前端已引入 `react-i18next` 作为 i18n 框架，资源字典位于 `src/i18n/zh-CN.ts`（嵌套对象结构），
由 `src/i18n/i18n.ts` 初始化全局 i18n 实例。

后端用户面向文案集中在 `app/services/messages_zh.py`（业务服务层）和
`app/domain/error_messages.py`（基础设施层）。

## 核心约定

### 前端

1. **所有用户面向文案必须通过 `t('key')` 引用**，不得硬编码中文字面量。
2. **字典文件**：`src/i18n/` 目录下的 `zh-CN.ts`（以及未来的 `en-US.ts` 等）为翻译源。
3. **占位符语法**：统一使用 `{name}`（已在 i18next 中配置 `prefix="{" suffix="}"`）。
4. **非 React 模块**（`api/*.ts`、`stores/*.ts`）通过导入 `i18n` 实例调用 `i18n.t('key')`。
5. **禁止导入具体字典**（如 `import { zhCN } from '../i18n/zh-CN'`），应使用 `t('key')` 或 `i18n.t('key')`。
   唯一例外：测试文件中直接验证字典内容（如 `expect(zhCN.enums.aggFunction.SUM).toBe('求和 SUM')`）。

### 后端

1. **所有用户面向文案必须通过 `MSG_*` 常量引用**，不得硬编码中文字面量。
2. **常量文件**：`app/services/messages_zh.py`（业务服务）、`app/domain/error_messages.py`（基础设施）。
3. **不拆分多语言版本**：后端目前仅服务中文前端，多语言文案管理待前端需求明确后再扩展。

## 添加新语言（以 en-US 为例）

### 前端

**Step 1**：复制 `src/i18n/zh-CN.ts` → `src/i18n/en-US.ts`，将所有中文值替换为英文。
确保导出名称为 `enUS`（PascalCase 文件名，camelCase 导出）。

**Step 2**：在 `src/i18n/i18n.ts` 中导入并注册资源：

```typescript
import { zhCN } from "./zh-CN";
import { enUS } from "./en-US";   // Step 1 新增

i18n.use(initReactI18next).init({
  resources: {
    "zh-CN": { translation: zhCN },
    "en-US": { translation: enUS },  // ← 新增
  },
  // ...
});
```

同步在 `src/i18n/index.ts` 中导出新字典：

```typescript
export { enUS } from "./en-US";
```

**Step 3**：添加语言切换 UI 组件并调用 `i18n.changeLanguage()`：

推荐在 `src/components/common/LanguageSwitch.tsx` 创建组件：

```typescript
import { Select } from "antd";
import { i18n } from "../../i18n";

const LANGS = [
  { value: "zh-CN", label: "中文" },
  { value: "en-US", label: "EN" },
];

export default function LanguageSwitch() {
  return (
    <Select
      value={i18n.language}
      options={LANGS}
      onChange={(value) => i18n.changeLanguage(value)}
      style={{ width: 80 }}
      variant="borderless"
    />
  );
}
```

然后在 `AppLayout.tsx` 的 Header 区域引入该组件即可。

### 后端

待前端确定需要后端返回多语言错误信息时，再将 `MSG_*` 常量扩展为按语言检索的结构。
当前阶段不做改动。

## 关键文件索引

| 文件 | 用途 |
|------|------|
| `frontend/src/i18n/zh-CN.ts` | 中文翻译字典（源） |
| `frontend/src/i18n/en-US.ts` | 英文翻译字典（扩展时创建） |
| `frontend/src/i18n/i18n.ts` | react-i18next 全局初始化 |
| `frontend/src/i18n/useTranslation.ts` | 组件内翻译 hook（对外签名固定） |
| `frontend/src/i18n/index.ts` | 统一导出 |
| `backend/app/services/messages_zh.py` | 后端业务服务层文案常量 |
| `backend/app/domain/error_messages.py` | 后端基础设施层文案常量 |

## 约束

- 翻译字典的 key 结构（嵌套层级）**不可随意修改**，如需调整须同步更新所有语言版本。
- 不得在字典值中嵌入 HTML 或代码片段，保持纯文本。
- 占位符 `{name}` 中的变量名须与调用方传入的 key 一致（区分大小写）。
