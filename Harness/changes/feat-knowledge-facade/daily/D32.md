## 二、方案对比（≥ 2 个候选，含取舍）

### 2.1 Facade 要不要调 LLM

| 维度 | **A 调 LLM 出答案** | **B 不调 LLM，出证据 + 确定性草稿**（采纳） |
|---|---|---|
| G5 可判定性 | 「答案好不好」是**主观**维度 ⇒ 通过率判据要靠人评 | 证据命中 / 权限结果 / 引用可溯源 **三项全客观** |
| 计量 / 预算 / 评测 | 引入 LLM ⇒ 要接三张皮（chat 已有同类实现，不能再来一份） | 不引入 ⇒ 本批零 LLM 依赖、零 token 成本 |
| 与 chat 的关系 | 两份 LLM 编排 ⇒ 口径漂移 | Facade 只做「取证据」，生成留给上层 |
| 结论 | ❌ | ✅ **采纳**（裁决 1）⇒ 契约里字段名就叫 `answerDraft`（草稿） |

### 2.2 通道枚举怎么落

| 维度 | **A 自由字符串** | **B 封闭枚举 + 请求层校验**（采纳） |
|---|---|---|
| 非法通道 | 漏到编排层被**静默忽略** ⇒ 调用方以为跑了第五路 | 422，且错误信息**点名**合法通道与非法值 |
| 可演进 | 随意 | 新增通道必须改枚举（刻意摩擦） |
| 结论 | ❌ | ✅ **采纳**（裁决 2） |

### 2.3 「采购薄别名无逻辑」怎么变成可判据

| 维度 | **A 文档承诺** | **B 人工 review 口头确认** | **C AST 守卫 + 导入守卫 + 路由守卫**（采纳） |
|---|---|---|---|
| 可判 | ❌ 口号 | ❌ 一次性 | ✅ 三条单测**持续**生效 |
| 抓什么 | —— | —— | 分支 / 循环 / try 节点、越界导入、第二个端点 |
| 守卫自身假绿 | —— | —— | 另加一条**守卫自检**（合成有分支的源码 ⇒ 守卫必须抓到） |
| 结论 | ❌ | ❌ | ✅ **采纳**（裁决 6） |

> ⚠️ 守卫 3（导入白名单）允许 `app.api.v1.knowledge_facade` —— 别名要拿到编排器与限流常量。
> 白名单里**不含**任何领域服务（`app.services.*`）⇒ 「逻辑只有一份」这件事被机器钉住。

## 三、契约（落定）

**请求** `POST /api/v1/semantic/knowledge/query`（裸 DTO，无信封）

| 字段 | 类型 | 必填 | 边界 |
|---|---|---|---|
| `domain` | str | ✅ | 1..20，去空白后非空；全空白 ⇒ 422 |
| `question` | str | ✅ | 1..500 |
| `channels` | list[str] | ✖ | 缺省 = 四路全开；取值 `GRAPH/METRIC/RAG/SQL` |
| `entityHints` | list[{type,code}] | ✖ | type ≤ 32、code ≤ 128 |
| `topK` | int | ✖ | 1..50，缺省 8 |
| `releaseId` | int | ✖ | ≥ 1；缺省 = 该域 ACTIVE |
| `scope` | {orgCodes, entityTypes, maxSecurityLevel} | ✖ | 每项 ≤ 32；`maxSecurityLevel ∈ L1/L2/L3`，缺省 L1；**只能收窄** |

**响应** `KnowledgeQueryResponse`（裸 DTO）

| 字段 | 说明 |
|---|---|
| `question` / `domain` | 回显 |
| `release` | `{id, version, manifestHash, degraded}`；**降级时 id/version/hash 全空且 degraded=true** |
| `answerDraft` | 确定性编排摘要（非 LLM 生成） |
| `entities[]` | `{type, code, name}` |
| `evidence[]` | `{channel, kind, ref, title, snippet, releaseId, releaseVersion, source}`；`source ∈ RELEASE / LIVE`（**D37 修订**：`LIVE` 是保留常量，**本批不产出** ⇒ 降级是**零证据 + 显式标记**，见 [`D37.md`](D37.md)） |
| `routeResults[]` | `{channel, status, itemCount, degradedReason, warnings[]}`；`status ∈ OK/EMPTY/DEGRADED/PENDING` |
| `warnings[]` | 全局警告（域不可见 / 路由降级 / 空集 …） |

**错误码**

| 情形 | HTTP | 包络 |
|---|---|---|
| 域为空 / 通道非法 / 长度越界 / releaseId 非法 | 422 | FastAPI `detail`（请求解析层） |
| 未登录 / token 失效 | 401 | 领域错误包络 |
| 限流 | 429 | 领域错误包络 + `Retry-After` |
| **域不可见** | **200** | 空结果 + `warnings[]`（**不是 403**，裁决 4） |

**采购薄别名** `POST /api/v1/procurement/knowledge/query`
请求体 = 主接口契约**去掉 `domain`**；其余逐字一致（共用基类 `_KnowledgeQueryBody` ⇒ 边界校验不漂移）。
