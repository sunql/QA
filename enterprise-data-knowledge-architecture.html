企业数据与知识架构

数据源 → 数据底座 → 数据中台 → 企业应用，LLM Wiki 知识层与数据双向绑定

四层主链路：从数据源到应用

  • • 数据源：ERP / PLM / MES / WMS / CRM / SRM / OA / IoT / 文件
  • • 数据底座：ODS→DWD→DWS→ADS 分层 + ETL/ELT 计算引擎
  • • 数据中台：以 Business Object / 指标体系对外供数
  • • 企业应用：BI、经营分析、AI、Agent、企业大脑消费能力

数据中台：统一语义与治理闭环

  • • MDM + Business Object 承载企业统一数据语义/标准/关系
  • • 指标体系保证口径一致，数据产品封装场景化供数
  • • 数据服务 / 资产 / 质量 / 治理四大能力闭环
  • • 向上层应用输出「使用数据/知识/能力」的统一入口

知识层：LLM Wiki 与数据双向绑定

  • • 知识模型：Entity / Relation / Claim / Evidence
  • • 治理要素：Knowledge Page / Authority / Rule
  • • 知识实体与 Business Object 双向绑定、语义对齐
  • • 为 AI 应用与 Agent 提供 grounded、可溯源的知识供给
