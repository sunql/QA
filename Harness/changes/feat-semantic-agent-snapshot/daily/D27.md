|---|---|

**集成用例的两个真实坑（都已修）**

1. **`manifest_json` 是 JSONB**：直接塞 JSON 字符串会被二次编码 ⇒ 撞
   `ck_semantic_release_manifest_is_object` CHECK ⇒ 改传 dict；
2. **哈希口径必须与 Registry 的规范化一致**：`manifest_hash` 必须是对
   `canonicalManifestJson(manifest)`（键序稳定、无空白、保留中文）的 SHA-256，
   不是随便的 `json.dumps`——否则 `verifySnapshotIntegrity` 读路径就拒绝；
3. **测试里造的发布行必须 commit**：createRun 走 HTTP（独立连接/事务），
   未提交的行对它不可见 ⇒ 钉不住（truncate 夹具负责清场）。

  Registry 先返回发布 7 再返回发布 9 ⇒ run A 钉 7、run B 钉 9，互不影响；

  发布改 ARCHIVED 后，已创建 run 的 detail 钉住快照原样。
